# Screenshot artwork

Updated 2026-10-19.

- `tech-overview.png`: analysis overview based on the first user-supplied screenshot.
- `tech-actions.png`: decisions and actions based on the second screenshot.
- Both images are 2362 x 1660 pixels.
- Treatment: cool paper / dark ink palette, cyan accents, restrained sharpening,
  dark technical framing, comic screen-tone margins and editorial typography.
- The original application layout is preserved; report text is fictional.
- The screenshot's recharge button is relabeled as model configuration for this
  presentation only. This does not change the application's actual button.
- Example reports include follow-up recommendations, execution and acceptance
  criteria in addition to summaries, decisions and action items.
- These are locally processed screenshots, not AI-generated interfaces.
- No screenshot was uploaded to an image generation service.
- Group names, member names, timestamps, message previews and entire report
  regions are covered with opaque pixels and replaced with fictional examples.
  No blur or reversible overlay layers are used. Exported PNG files are flattened
  and do not copy source image metadata.
- The original unprocessed screenshot files are not included in this directory.

The earlier cartoon mascot concept has been replaced and is not used by the README.
